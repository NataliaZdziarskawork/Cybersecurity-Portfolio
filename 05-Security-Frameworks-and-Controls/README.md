# Security Frameworks and Controls

## Project Overview

This project explains the purpose of cybersecurity frameworks and security controls.

It describes why organizations use them to reduce cybersecurity risks, protect information, and improve their overall security posture.

This project was created as part of the Google Cybersecurity Professional Certificate.

---

## What Are Security Frameworks?

Security frameworks are structured sets of guidelines, best practices, and standards that help organizations build and maintain effective cybersecurity programs.

Frameworks provide a consistent approach to identifying risks, protecting assets, responding to security incidents, and improving security over time.

Organizations use security frameworks to strengthen their security posture and support compliance with legal and regulatory requirements.

---

## What Are Security Controls?

Security controls are safeguards designed to protect an organization's systems, networks, applications, and data from cyber threats.

Security controls help reduce risks by preventing attacks, detecting suspicious activity, and responding to security incidents.

---

## Why Do Organizations Use Security Frameworks and Controls?

Organizations use security frameworks and controls to:

- Identify and manage cybersecurity risks.
- Protect sensitive information.
- Reduce the likelihood of cyberattacks.
- Improve incident response.
- Support legal and regulatory compliance.
- Strengthen business continuity.

---

## Types of Security Controls

## Administrative Controls

Administrative controls include security policies, procedures, employee training, and risk management practices.

### Examples

- Security policies
- Security awareness training
- Incident response plans

---

## Technical Controls

Technical controls use technology to protect systems and data.

### Examples

- Multi-Factor Authentication (MFA)
- Firewalls
- Antivirus software
- Encryption
- Security Information and Event Management (SIEM)

---

## Physical Controls

Physical controls protect buildings, equipment, and other physical assets.

### Examples

- Security cameras (CCTV)
- Access cards
- Security guards
- Locked server rooms

---

# Common Cybersecurity Frameworks

## NIST Cybersecurity Framework

The NIST Cybersecurity Framework helps organizations identify, protect, detect, respond to, and recover from cybersecurity incidents.

---

## ISO/IEC 27001

ISO/IEC 27001 is an international standard for establishing, implementing, maintaining, and improving an Information Security Management System (ISMS).

---

## CIS Controls

The CIS Controls are a prioritized set of security best practices designed to help organizations defend against common cyber threats.

---

## Key Takeaways

Security frameworks provide guidance for managing cybersecurity, while security controls are the practical measures used to protect an organization.

Using both frameworks and controls helps organizations reduce risks, improve security, and respond effectively to cyber threats.

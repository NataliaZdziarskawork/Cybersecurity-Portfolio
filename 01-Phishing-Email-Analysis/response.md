# Phishing Response

## Immediate Actions

If an employee receives this message, they should:

1. Do not click the suspicious URL.
2. Do not open the ZIP attachment.
3. Do not provide or enter login credentials.
4. Report the message as suspected phishing according to the organization's security procedure.
5. Preserve the email as evidence if requested by the security team.

## If Credentials Were Entered

If the employee already entered their credentials, they should:

1. Report the incident immediately.
2. Change the affected password using the legitimate service.
3. Enable Multi-Factor Authentication (MFA) if available.
4. Follow the organization's incident response procedure.
5. Monitor the account for suspicious activity.

## Important Note

A VPN does not make a phishing link safe. The safest response is to avoid interacting with suspicious links and attachments and report the message for investigation.

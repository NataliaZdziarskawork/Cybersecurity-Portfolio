# Security Controls

## Overview

Security control to zabezpieczenie lub działanie stosowane w celu ograniczenia ryzyka.

## Examples

- Firewall — pomaga kontrolować ruch sieciowy i ograniczać nieautoryzowane połączenia.
- MFA — pomaga ograniczyć ryzyko przejęcia konta.
- Encryption — pomaga chronić dane przed nieuprawnionym odczytem.
- Access control — określa, kto może uzyskać dostęp do określonych zasobów.
- Security monitoring — pomaga wykrywać podejrzaną aktywność.



## Example Scenario

Firma ma kilka problemów związanych z bezpieczeństwem:

- niezałataną lukę na serwerze,
- zbyt szerokie uprawnienia pracowników,
- brak MFA,
- brak monitorowania logów.

### Recommended Controls

- Załatanie luki — zmniejsza ryzyko wykorzystania podatności.
- Access control i least privilege — ograniczają dostęp pracowników do niezbędnych zasobów.
- MFA — ogranicza ryzyko przejęcia kont.
- Security monitoring — pomaga wykrywać podejrzaną aktywność.

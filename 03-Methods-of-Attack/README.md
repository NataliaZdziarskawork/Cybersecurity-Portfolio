# Methods of Attack

## Project Overview

This project covers common cyberattack methods, how they work, their impact on organizations, and basic protection strategies.

## 1. Phishing

### What is it?

Phishing is an attempt to steal data by impersonating a trusted person or organization.

### How does it work?

The attacker sends fake emails or messages containing malicious links or requests for sensitive information.

### Impact on Organizations

- Theft of login credentials
- Account takeover
- Unauthorized access to systems

### Protection

- Multi-Factor Authentication (MFA)
- Employee security training
- Sender and domain verification

---

## 2. Malware

### What is it?

Malware is malicious software designed to infect computers, networks, or systems.

### How does it work?

It can be installed after clicking a malicious link, opening an infected attachment, or downloading unsafe files.

### Impact

- Data loss
- System damage
- Unauthorized access

### Protection

- Antivirus solutions
- Regular updates
- Safe downloading practices

---

## 3. Ransomware

### What is it?

Ransomware is malware that blocks access to data or encrypts files and demands payment for recovery.

### How does it work?

The attacker infects a system, spreads through the environment, encrypts data, and demands a ransom.

### Impact

- Operational downtime
- Financial losses
- Reputation damage
- Legal risks

### Protection

- Network segmentation
- Multi-Factor Authentication (MFA)
- Regular offline backups
- SIEM monitoring

---

## 4. Password Attacks

### What is it?

Password attacks are attempts to crack, guess, or steal user credentials.

### Common Methods

**Brute Force**

Automatic attempts using many possible password combinations.

**Dictionary Attack**

Attempts using lists of commonly used passwords.

**Credential Stuffing**

Using leaked passwords from other websites.

**Password Phishing**

Tricking users into providing login credentials.

### Impact

- Account takeover
- Privilege escalation
- Data leaks
- Unauthorized system access

### Protection

- MFA
- Password managers
- Strong password policies
- Detection of unusual login activity

---

## 5. DoS / DDoS Attacks

### What is it?

DoS and DDoS attacks attempt to make services unavailable by overwhelming them with large amounts of traffic.

### How does it work?

- DoS: attack from a single source.
- DDoS: attack from multiple devices, usually a botnet.

### Impact

- Website and application downtime
- Financial losses
- Operational interruptions

### Protection

- Web Application Firewall (WAF)
- Rate limiting
- CDN protection
- Traffic filtering
- Scrubbing centers
- Network segmentation

---

## 6. Social Engineering

### What is it?

Social engineering is the manipulation of people to gain access, obtain information, or make them perform unsafe actions.

### How does it work?

Examples include:

- Fake emails
- Text message scams
- Fake login pages
- Phone scams
- Physical access attacks

### Impact

- Data leaks
- Account takeover
- Malware infections
- Loss of system control

### Protection

- Security awareness training
- Security policies
- Identity verification
- Access restrictions

---

## 7. Insider Threats

### What is it?

Insider threats come from people within an organization, including employees, partners, or suppliers.

### How does it work?

Examples:

- Accidental mistakes
- Compromised employee accounts
- Intentional malicious actions

### Impact

- Data leakage
- Sabotage
- Information theft
- System damage

### Protection

- Log monitoring
- Data Loss Prevention (DLP)
- Least privilege principle
- Network segmentation
- Access audits

# Methods of Attack

## Project Overview

Ten projekt przedstawia podstawowe metody ataków wykorzystywane w cybersecurity.

Celem projektu jest zrozumienie, jak różne rodzaje ataków mogą wpływać na użytkowników, systemy, sieci i dane.

## Attack Methods Covered

- Phishing
- Spear phishing
- Malware
- Virus
- Worm
- Ransomware
- Trojan
- Brute-force attack
- Credential stuffing
- DoS and DDoS
- Man-in-the-Middle (MITM)
- Social engineering

## Key Takeaways

Ataki mogą wykorzystywać zarówno podatności techniczne, jak i błędy lub manipulację użytkownikami.

Security Analyst powinien potrafić rozpoznać rodzaj ataku, ocenić potencjalne ryzyko i odpowiednio zareagować.

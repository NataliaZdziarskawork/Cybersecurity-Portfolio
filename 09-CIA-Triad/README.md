# CIA Triad

## Project Overview

This project explains the CIA Triad, one of the fundamental models in cybersecurity.

The CIA Triad consists of three core security principles: Confidentiality, Integrity, and Availability.

Together, these principles help organizations protect information and maintain secure business operations.

This project was created as part of the Google Cybersecurity Professional Certificate.

---

## What Is the CIA Triad?

The CIA Triad is a cybersecurity model used to guide the design and implementation of security controls.

It helps organizations protect information by focusing on three essential principles:

- Confidentiality
- Integrity
- Availability

These principles work together to ensure that information remains secure, accurate, and accessible to authorized users.

---

# Confidentiality

## Definition

Confidentiality means protecting sensitive information from unauthorized access or disclosure.

Only authorized users should be able to view confidential data.

## Examples of Security Controls

- Multi-Factor Authentication (MFA)
- Strong passwords
- Data encryption
- Role-Based Access Control (RBAC)

## Example

Only members of the Human Resources department can access employee records.

---

# Integrity

## Definition

Integrity means ensuring that information remains accurate, complete, and has not been modified without authorization.

Organizations use security controls to prevent unauthorized changes to data.

## Examples of Security Controls

- File integrity monitoring
- Digital signatures
- Access controls
- Audit logs

## Example

A financial database records every transaction accurately, and unauthorized changes are detected immediately.

---

# Availability

## Definition

Availability means ensuring that systems, applications, and data are accessible whenever authorized users need them.

Organizations implement measures to minimize downtime and maintain business continuity.

## Examples of Security Controls

- Data backups
- Disaster recovery plans
- Redundant systems
- System monitoring

## Example

A hospital's medical records system remains available 24/7 so healthcare professionals can access patient information when needed.

---

## Why Is the CIA Triad Important?

The CIA Triad helps organizations:

- Protect sensitive information.
- Maintain data accuracy.
- Ensure continuous access to critical systems.
- Reduce cybersecurity risks.
- Support business continuity.

It serves as a foundation for many cybersecurity frameworks, policies, and security controls.

---

## Key Takeaways

The CIA Triad is one of the most important concepts in cybersecurity.

Maintaining confidentiality, integrity, and availability helps organizations protect information, reduce security risks, and support reliable business operations.

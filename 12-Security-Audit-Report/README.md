# Security Audit Report

## Project Overview

This project documents a security audit exercise focused on identifying security risks, reviewing security practices, and providing recommendations to improve an organization's security posture.

The audit was performed as part of the Google Cybersecurity Professional Certificate learning activities.

---

## Audit Objective

The goal of this security audit was to review existing security practices, identify potential risks, and recommend improvements that could help protect organizational systems, data, and users.

---

## Audit Scope

The audit focused on reviewing key areas of cybersecurity, including:

- Access control
- Authentication practices
- Data protection
- Security awareness
- Software updates
- Incident response procedures
- Security policies

---

# Security Audit Checklist Review

## Access Control

### Observation

User access should be managed according to job responsibilities.

### Risk

Excessive permissions may allow unauthorized users to access sensitive information.

### Recommendation

Implement the principle of least privilege and regularly review user permissions.

---

## Authentication Security

### Observation

Strong authentication methods are important for protecting user accounts.

### Risk

Weak authentication may lead to account compromise.

### Recommendation

Enable Multi-Factor Authentication (MFA) for important systems and accounts.

---

## Software Updates and Patch Management

### Observation

Systems and applications require regular updates.

### Risk

Outdated software may contain vulnerabilities that attackers can exploit.

### Recommendation

Apply security patches regularly and maintain an update process.

---

## Security Awareness Training

### Observation

Employees should understand common cybersecurity threats.

### Risk

Human errors may lead to phishing attacks or data exposure.

### Recommendation

Provide regular cybersecurity awareness and phishing training.

---

## Data Protection

### Observation

Sensitive information requires appropriate protection.

### Risk

Unauthorized access or data leaks may impact the organization.

### Recommendation

Use encryption, access controls, and secure data handling procedures.

---

# Identified Risks

During the audit, the following common cybersecurity risks were identified:

- Weak authentication practices.
- Excessive user permissions.
- Lack of employee security awareness.
- Outdated software.
- Improper protection of sensitive data.

---

# Security Recommendations

Recommended improvements:

- Implement Multi-Factor Authentication (MFA).
- Review and limit user permissions.
- Perform regular security training.
- Maintain updated systems.
- Monitor security events.
- Conduct regular security audits.

---

# Audit Conclusion

A security audit helps organizations identify weaknesses and improve their security practices.

Regular assessments allow security teams to reduce risks, strengthen controls, and better protect organizational assets.
